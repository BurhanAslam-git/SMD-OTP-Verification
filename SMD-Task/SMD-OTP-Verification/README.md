# SMD OTP Verification (React Native / Expo)

A mobile app that verifies a phone number with a **random 6-digit one-time password (OTP)**.
The OTP is generated by the app's own server, which runs on the laptop inside `npx expo start`, and is printed in that terminal. Every step is logged there as proof: **OTP generated → OTP entered → verified → registered**. It is free: no SMS service or paid account is needed.

## How to use

1. Enter a phone number with its country code, e.g. `+923001234567`, and tap **Send OTP**.
2. Read the OTP in the laptop terminal (the `npx expo start` window).
3. Type the OTP in the app and tap **Verify OTP**.
4. A correct OTP shows **Verification Successful** and the user ID the number was registered with. A wrong OTP shows an error and how many tries are left.

## Run it

Install **Expo Go** from the Play Store (or App Store) and update it to the latest version. On Android, scan the QR code with the **Scan QR code** button inside Expo Go; the phone camera or an older build of this app won't open it. Keep the terminal visible: the OTPs appear there.

```bash
npm install
npm start           # phone and laptop on the same Wi-Fi
npm run tunnel      # any network, even mobile data (use this if the scan times out)
```

If the scan fails with "Failed to download remote update" or keeps loading, the phone can't reach the laptop over Wi-Fi. Use `npm run tunnel`, or connect the phone by USB with USB debugging on, then run:

```bash
adb reverse tcp:8081 tcp:8081
npx expo start --localhost
```

## How it works

```
 Phone (Expo Go)                          Laptop (npx expo start)
 ---------------                          -----------------------
 Send OTP   -- POST /api/otp/send ----->  random 6-digit OTP, printed in the console
            <-- { sent: true } ---------  (the OTP is never sent back to the phone)
 Verify OTP -- POST /api/otp/verify --->  compares it with the stored OTP
            <-- verified + user ID -----  logs VERIFIED + REGISTERED, or REJECTED
```

- The OTP is random (`crypto.getRandomValues`), valid for **5 minutes** and works **once**.
- **3 wrong tries** cancel the OTP and a new one must be requested (**Resend OTP**).
- A verified number is registered with a user ID (`SMD-0001`, `SMD-0002`, …). Verifying the same number again shows it is already registered.
- OTPs and registered users are kept in the server's memory and are cleared when the server stops.

## Project structure

```
App.js                          Phone verification screen (UI + calls to the server)
src/app/_layout.js              Expo Router layout
src/app/index.js                Shows App.js as the home screen
src/app/api/otp/send+api.js     POST: generate the OTP and print it in the console
src/app/api/otp/verify+api.js   POST: check the OTP and register the number
src/server/otp-store.js         OTP generation, expiry, tries and registered users
src/server/otp-log.js           Console log lines for each step
```

## API

| Method | Path | Body | Success response |
| --- | --- | --- | --- |
| POST | `/api/otp/send` | `{ "phone": "+923001234567" }` | `{ "sent": true, "expiresInMinutes": 5 }` |
| POST | `/api/otp/verify` | `{ "phone": "+923001234567", "otp": "257038" }` | `{ "verified": true, "userId": "SMD-0001", "newUser": true }` |

Errors return `{ "error": "<message>" }` with status 400 (bad input), 401 (wrong OTP), 404 (no active OTP), 410 (expired) or 429 (too many tries).
